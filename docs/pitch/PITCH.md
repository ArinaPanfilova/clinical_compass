# Компас — материалы к предзащите (черновик)

Выступление — 3 минуты, вопросы — 5 минут. Структура задана организаторами: идея → прототип →
метрики → планы → команда. Числа взяты из `evaluation/results/` и пересчитываются скриптами.

## Слайды (≈ 20 секунд на слайд)

1. **Компас — цифровой ассистент врача первичного звена** для взрослых с тревогой и депрессией.
   Три кабинета: врач, пациент, исследователь. Решения принимает только врач.

2. **Идея.** Терапевт видит тревогу и депрессию каждый день, но между визитами пациент «пропадает»,
   а мысли о самоповреждении всплывают случайно. Измерение по валидированным шкалам → правила с
   источниками → сигнал врачу → решение врача → наблюдение. Это measurement-based care
   (метаанализ Zhu 2021: выше шанс ремиссии, OR 1,83), а не «чат-бот-психолог».

3. **Прототип: безопасность прежде всего.** Пациент отвечает на п.9 PHQ-9 → врачу за 14 мс приходит
   срочный сигнал → «принять в работу» → решение с причиной в журнале. Не принят за 60 с — уходит
   заместителю. Направление к психиатру — «обязательно / желательно» × «экстренно / срочно / планово».

4. **Прототип: Авиандр в рамках инструкции.** Карточка сверена с ГРЛС (листок-вкладыш 29.07.2026).
   Три честных статуса: «можно рассмотреть / не подходит / недостаточно данных» — неизвестное не
   считается отсутствием противопоказания. Выписка → факты с цитатами → врач подтверждает.

5. **Отличие: наблюдение применения Авиандра.** Из тех же данных, что вводят врач и пациент:
   кому назначали, динамика GAD-7 по исходу курса, причины отмен, приверженность, НЯ.
   Индекс устойчивой пользы — ответ без вреда среди всех начавших (ITT, 95 % ДИ).
   Исследователь видит только обезличенные агрегаты, группы < 5 скрыты.

6. **Метрики** (синтетика, без реальных пациентов):
   * алертинг: чувствительность 0,89, специфичность 0,93; «обязательно к психиатру» — 0,96 / 0,96;
   * доставка сигнала врачу — 14 мс (p50), потерь 0 из 200;
   * 100 одновременных сессий — 0 ошибок, p95 ≤ 1,8 с;
   * `kill -9` сервера посреди потока — 0 потерь из 387 подтверждённых, восстановление 2,6 с;
   * извлечение из выписок: препараты F1 0,96; ни разу «противопоказаний нет» при их наличии;
   * 300+ автотестов, 0 несанкционированных доступов в матрице прав.

7. **Научная основа.** PHQ-9 и GAD-7 в валидированных русских версиях (Золотарева 2023), пороги и
   MCID с источниками, КР Минздрава, инструкция ГРЛС, NICE NG225 (алерт — не прогноз суицида).

8. **Планы внедрения.** Экспертная проверка правил психиатром → теневой режим → пилот в одной
   поликлинике. Интеграция с МИС и ЕГИСЗ, оценка статуса медицинского изделия, MFA, Postgres.
   Наблюдение применения — источник данных реальной практики для пострегистрационного мониторинга.

9. **Команда, благодарности, QR на GitHub.**
