# Время доставки алерта врачу

Пациент отправляет PHQ-9 с п.9 = 2 → алерт создаётся в той же транзакции, что и данные → клиент врача получает его по SSE. Клиент и сервер на одной машине, без внешней сети.

| Процессов | n | Потеряно | Сохранено → алерт создан, мс (p50 / p95 / max) | Отправка пациентом → получено врачом, мс (p50 / p95 / max) |
|---|---|---|---|---|
| 1 | 100 | 0 | 3.0 / 5.0 / 51.0 | 9.7 / 63.7 / 132.8 |
| 4 | 100 | 0 | 3.0 / 5.0 / 107.0 | 13.8 / 60.4 / 122.9 |

При нескольких процессах алерт, созданный в соседнем процессе, доходит через проверку БД (не реже раза в 0,5 с), иначе — сразу через брокер процесса. Цели прототипа (проектный документ, 13.4): создание ≤ 5 с, доставка ≤ 30 с.
Время реакции человека — отдельный регламент, а не метрика программы.
